# Customer Segmentation with Clustering

Customer segmentation project using unsupervised learning on a large e-commerce dataset.

The original dataset contained 951,669 transaction records. After cleaning and aggregation, the analysis produced a customer-level dataset of 68,300 customers across 47 countries.

## Analysis

Customer-level features were created from the transaction data and standardised before clustering.

I explored the cluster structure using:

- K-means clustering
- Hierarchical clustering
- Elbow method
- Silhouette analysis
- PCA
- t-SNE

The analysis resulted in five customer segments with different purchasing patterns.
